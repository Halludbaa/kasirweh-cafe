# Kasirweh Cafe

Kasirweh Cafe adalah aplikasi kasir sederhana untuk keperluan bisnis kecil/mikro. Fitur utama aplikasi ini sebagai berikut:

- Receipt Print
- Cash or Static QRIS Payment
- Customize Catalog
- Customize Store Name
